## Program Explanation
```
The main thing being used is the inbuilt loop and global variables. I have reused global variables across the code to let loops pass important data to each other (not always best practice). I made one change, the LED lights are implied to be a single colour bulb. since the bulb pulses, it would be difficult to identify the bulb in reaction mode with the bulb at the peak of its pulse. so, i used a colour bulb, with red being used for the pulses and green being used for the reaction
```
